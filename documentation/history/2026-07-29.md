# 2026-07-29 — Date placeholders in "Folders to force update" (#65)

Implements [#65](https://github.com/dsebastien/obsidian-dataview-serializer/issues/65).
Inspiration: `expression-evaluator.ts` in `obsidian-starter-kit-plugin` (same `{{name}}`
grammar, same date-fns backing), extended with offsets and custom formats.

## Problem

"Folders to force update" only accepted static paths. Periodic Notes users had to either
list a whole year (`Daily/2026` → force-updates hundreds of historical notes on every
vault change) or edit the setting every month.

## What was added

- `src/app/utils/resolve-path-placeholders.fn.ts`
    - `resolvePathPlaceholders(input, referenceDate = new Date())`
    - `containsPathPlaceholders(input)`
- Grammar: `{{name[±offset][:format]}}`
    - names (case-insensitive): `year`, `quarter`, `month`, `monthName`, `week`, `date`, `day`
    - offset unit follows the name (`{{month-1}}` = previous month, `{{date-7}}` = 7 days ago,
      `{{week+1}}` = next ISO week)
    - format = a date-fns format string overriding the default rendering
      (`{{date:MM-MMM}}` → `07-Jul`, `{{week:RRRR-'CW'II}}` → `2026-CW30`)
- Wired into `plugin.ts#processForceUpdateFiles`: folders are resolved **on every run**
  (not at save time), then the existing `file.path.startsWith(folder)` prefix match applies.
- Settings tab: force-update entries containing placeholders show
  "Currently resolves to: …"; the setting description documents the syntax and shows a
  live example; the search input's placeholder hints at the syntax.
  `ArgsSearchAndRemove` gained `supportsPlaceholders?: boolean` and its `description`
  widened to `string | DocumentFragment`.

## Decisions

- **Defaults are numeric and locale-independent** (`{{month}}` → `07`, `{{week}}` → `30`)
  so resolved paths stay identical across devices/languages. The issue's `07-Jul` /
  `2026-CW30` shapes are reachable via `{{month}}-{{monthName}}` and
  `{{week:RRRR-'CW'II}}`.
- **`monthname` must precede `month` in the regex alternation** — otherwise `month` matches
  the prefix and `{{monthName}}` never resolves.
- **Unknown placeholders and invalid formats are left verbatim** rather than dropped: a typo
  then matches no folder (nothing is force-updated) instead of silently matching a wrong,
  broader path. The settings preview makes the mistake visible.
- **Scope limited to "Folders to force update"** (what #65 asked for). "Folders to scan" and
  "Folders to ignore" stay static; the plumbing (`supportsPlaceholders`) makes extending
  them a one-line change if ever requested.
- **`{{current-period}}`** from the issue was deliberately not implemented — it would require
  reading Periodic Notes' configuration and guessing its folder layout. `{{month}}` +
  `{{month-1}}` covers the same need explicitly.
- Week numbers use the **ISO** week system (Monday-based), matching the starter kit.
